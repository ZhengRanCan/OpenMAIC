# F27 验证计划

## 允许的验证方式

- 阅读相关合同、完成证据、课后领域契约、可靠性和身份持久化约束。
- 使用只读代码搜索与 Git 历史核对课堂事实到回执状态的已提交实现。
- 对每条发现交叉核对代码、测试、事务、幂等和已有证据。

## 禁止事项

- 不运行测试、构建、格式化、Worker、数据库或真实投递命令。
- 不修改被审查代码、历史合同或其他 Feature 文件及外部状态，不干扰 F24 或其他并行工作；仅可写入 F27 报告与 Harness 状态文档。

## 通过前检查

- [x] 报告覆盖 Candidate、closeout、Outbox、Worker、回执、保留/删除和长期画像边界。
- [x] 每条发现有精确代码证据和可复述触发路径。
- [x] 报告明确记录已审查提交、排除项、待确认项和只读约束遵守情况。
