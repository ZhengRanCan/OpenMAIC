# F25 验证计划

## 允许的验证方式

- 阅读 AGENTS、Registry、进度面板、F16–F23 合同、相关完成证据和最小架构/约束文档。
- 使用只读代码搜索和 Git 历史核对 Feature 的已提交实现。
- 对每条发现交叉核对合同、代码、测试与已有证据。

## 禁止事项

- 不运行测试、构建、格式化、数据库迁移、真实生成或任何可能写缓存/产物的脚本。
- 不修改被审查代码、历史合同或其他 Feature 文件，不做 Git 写操作，不干扰 F24 或其他并行工作；仅可写入 F25 报告与 Harness 状态文档。
