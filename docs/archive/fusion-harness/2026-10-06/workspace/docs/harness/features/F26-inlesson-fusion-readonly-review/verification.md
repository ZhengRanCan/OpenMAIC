# F26 验证计划

## 允许的验证方式

- 阅读相关合同、完成证据、领域契约、接入时序和安全约束。
- 使用只读代码搜索与 Git 历史核对 checkpoint 到观察事实的已提交实现。
- 对每条发现交叉核对代码、测试、事务边界和已有证据。

## 禁止事项

- 不运行测试、构建、格式化、数据库或真实课堂命令。
- 不修改被审查代码、历史合同或其他 Feature 文件及外部状态，不干扰 F24 或其他并行工作；仅可写入 F26 报告与 Harness 状态文档。

## 通过前检查

- [x] 报告覆盖 checkpoint、事件、诊断、Planner、CAS、Scene 调整和课堂事实。
- [x] 每条发现有精确代码证据和可复述触发路径。
- [x] 报告明确记录已审查提交、排除项、待确认项和只读约束遵守情况。
